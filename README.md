# kernelmaker.github.io

Zhao Song's blog on database internals — MySQL/InnoDB, PostgreSQL, RocksDB, and more.

Built with [Jekyll](https://jekyllrb.com/). Custom "Blueprint" theme: IBM Plex Sans/Mono (self-hosted in `public/fonts/`), styles in `public/css/main.scss`, layouts in `_layouts/`.

## Local development

```sh
bundle install
bundle exec jekyll serve   # http://localhost:4000
```

Posts live in `_posts/`, with images under `public/images/<date>/`.
